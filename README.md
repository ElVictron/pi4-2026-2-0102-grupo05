# Sistema de Gerenciamento de Biblioteca

Projeto Integrador IV — curso de Sistemas de Informação, Escola Politécnica
da Pontifícia Universidade Católica de Campinas (PUC-Campinas). Turma
2026-2, grupo 05 (0102).

Orientador: Douglas Henrique de Siqueira de Abreu

## O problema

Hoje o responsável pela biblioteca controla livros, usuários e empréstimos
de forma manual, usando planilhas. Isso dificulta verificar rapidamente
quais livros estão disponíveis e acompanhar devoluções e empréstimos em
andamento.

## Objetivo

Construir um sistema web que centralize o controle de livros, usuários e
empréstimos, facilitando a consulta da disponibilidade dos exemplares e o
acompanhamento das devoluções.

**Objetivos específicos:**

- Cadastrar e consultar livros e seus exemplares.
- Cadastrar e consultar usuários da biblioteca.
- Registrar empréstimos e devoluções de livros.
- Acompanhar a disponibilidade dos livros e os empréstimos em andamento.

## Escopo

| Entregável | Descrição |
| --- | --- |
| Cadastro de livros | Cadastrar título, autor, ISBN e quantidade de exemplares |
| Consulta de livros | Pesquisar um livro e ver seus dados e disponibilidade |
| Cadastro de usuários | Cadastrar nome, CPF e contato |
| Consulta de usuários | Pesquisar um usuário e ver seus dados e empréstimos |
| Registro de empréstimo | Vincular usuário e livro disponível, registrando o empréstimo |
| Registro de devolução | Registrar devolução e liberar o exemplar |
| Controle de disponibilidade | Mostrar quais livros têm exemplares disponíveis |
| Consulta de empréstimos | Listar empréstimos ativos, devolvidos e atrasados |

**Fora de escopo:** aplicativo mobile nativo, sistema de multas e
pagamentos, reserva de livros e integração com bibliotecas externas — o
projeto é uma aplicação web responsiva, sem essas funcionalidades na
primeira versão.
